# Task Experience Loop — Always-on profile

This profile is optional. Copy the rules below into your personal global
`AGENTS.md` only when you want TEL active in every project.

## TEL

- At session start, run `tel context --stdout` from the current project's working directory.
- Use TEL only for durable memory, never as an activity log.
- When a decision, reusable pattern, global noun, task state, or compact review may need to change, use the `tel` skill; it owns TEL formats and commands.
- Compact source-record changes require user approval.
